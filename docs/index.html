Voidglow

A minimalist CRT terminal-style Firefox new tab page.

What it does

  • Pure black new tab interface with phosphor green text.
  • Search bar with engine shortcuts.
  • Quick access bookmarks, notes, and timers.
  • Ambient rain sounds and daily word content.
  • Custom backgrounds and compact CRT styling.
  • Settings page with theme switcher, including the new Voidglow theme.

Installation

  1. Download the latest `.xpi` from GitHub Releases.
  2. Open Firefox and visit about:addons.
  3. Click the gear icon and choose Install Add-on From File.
  4. Select the downloaded package and confirm.

If you want to test the source directly, load manifest.json as a temporary add-on in Firefox.
